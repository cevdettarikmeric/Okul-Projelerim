# 🎓 School Development Projects Archive

Bu repository, eğitim sürecim boyunca geliştirdiğim tüm web ve mobil uygulama projelerini içeren kapsamlı bir dijital arşive dönüştürülmüştür. Notlarımda belirttiğim "öğrenci değil geliştirici" vizyonu doğrultusunda, her çalışma bir öğrenme basamağı olarak organize edilmiştir.

## 📂 Repository Yapısı

Projeler, notlardaki profesyonel tavsiyelere uygun olarak ana kategorilere ve haftalık klasörlere ayrılmıştır:

### 🌐 Web Tasarım & Frontend

* 
**Haftalık Müfredat:** HTML5, CSS3 ve JavaScript standartlarına uygun kodlama pratikleri.


* **Modern Frameworkler:** Bootstrap kütüphanesi ile duyarlı (responsive) tasarım uygulamaları (15. ve 16. hafta içerikleri).
* 
**JavaScript Pratikleri:** DOM manipülasyonu, form doğrulama ve interaktif kullanıcı arayüzleri.


* **Sınav Hazırlıkları:** Yazılı dönemleri için geliştirilmiş özel senaryolar ve çözüm dosyaları.

### 📱 Mobil Uygulama Geliştirme

* **Arayüz Tasarımı:** Mobil bileşen hiyerarşisi ve kullanıcı deneyimi odaklı yerleşim çalışmaları.
* **Sınav Projeleri:** `donem1sinav1` ve `donem1sinav2` gibi belirli teknik isterleri karşılayan sınav uygulamaları.

## 🛠️ Kullanılan Teknolojiler

Notlarımda analiz ettiğim profesyonel araç setini bu projelerde aktif olarak kullandım:

* 
**Frontend:** HTML5, CSS3, JavaScript, Bootstrap.


* 
**Versiyon Kontrol:** Git & GitHub (Commit geçmişi ile süreç takibi).


* 
**Gelecek Hedefleri:** PHP ve MySQL tabanlı dinamik projeler için temel oluşturma.



## 🚀 Neden Bu Arşivi Tutuyorum?

Notlarımdaki stratejik hedeflerim şunlardır:

1. 
**Gelişim Kanıtı:** İlk haftadan bugüne kadar olan teknik ilerlemeyi belgelemek.


2. 
**Disiplinli Sunum:** 50+ projeyi tek tek değil, profesyonel bir hiyerarşi içinde sunmak.


3. 
**Portfolyo Temeli:** Bir "Junior Developer" adayı olarak güçlü bir teknik geçmiş (history) oluşturmak.
